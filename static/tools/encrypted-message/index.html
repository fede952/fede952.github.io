Encrypted Message Link

Encrypt a note in your browser and share it as a link

Use a long passphrase. Anyone who has both the link and the passphrase can read the message.

How to send it safely
  1. Send the link over one channel (for example email).
  2. Send the passphrase over a different one (for example a phone call or another messenger) — never in the same message.
  3. The link does not expire or self-destruct: anyone with the link and the passphrase can open it for as long as they keep the link. Nothing is stored on any server, so there is nothing to delete.
