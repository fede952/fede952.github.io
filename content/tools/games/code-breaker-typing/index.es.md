## Cómo Jugar

- **Haz clic en "INITIALIZE HACK"** para iniciar el temporizador y revelar un fragmento de código.
- **Escribe el fragmento exactamente** como se muestra — cada carácter, espacio y símbolo importa.
- **Vence el reloj de 30 segundos** para vulnerar el sistema.
- Si se acaba el tiempo, la conexión se termina. Pulsa **RETRY HACK** para intentarlo de nuevo.
