Le système cible est verrouillé derrière un pare-feu chiffré. Votre seul moyen d'entrer ? **Tapez la séquence de code exacte avant la fin du temps imparti.** Une seule erreur et vous êtes bloqué. À quelle vitesse vos doigts peuvent-ils aller ?

## Comment Jouer

- **Cliquez sur "INITIALIZE HACK"** pour lancer le chronomètre et révéler un extrait de code.
- **Tapez l'extrait exactement** tel qu'il est affiché — chaque caractère, espace et symbole compte.
- **Battez le chronomètre de 30 secondes** pour pénétrer le système.
- Si le temps s'écoule, la connexion est terminée. Appuyez sur **RETRY HACK** pour réessayer.
