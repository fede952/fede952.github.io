Microsoft atribuye ataques globales a Wi-Fi de hoteles a Midnight Blizzard (APT29) de Rusia, utilizando malware personalizado para comprometer cuentas de Microsoft 365.

{{< cyber-report severity="High" source="BleepingComputer" target="Redes Wi-Fi de hoteles y cuentas de Microsoft 365" >}}

Microsoft ha identificado una campaña cibernética global dirigida a redes Wi-Fi de hoteles, atribuyéndola al actor de amenazas ruso Midnight Blizzard, también conocido como APT29. Los ataques aprovechan malware personalizado para comprometer cuentas de Microsoft 365, lo que indica una amenaza sofisticada y persistente.

{{< ad-banner >}}

La campaña subraya los riesgos asociados con las redes Wi-Fi públicas en hoteles, que a menudo son confiadas por viajeros de negocios y pueden servir como puerta de entrada a credenciales corporativas. El uso de malware personalizado por parte de APT29 sugiere un enfoque adaptado para evadir la detección y mantener el acceso.

Las organizaciones con empleados que viajan con frecuencia deben ser conscientes de esta amenaza y reforzar las medidas de seguridad, como imponer la autenticación multifactor y monitorear actividades inusuales en las cuentas, especialmente cuando se accede desde redes de hoteles.

{{< netrunner-insight >}}

Para los analistas de SOC, esta campaña resalta la necesidad de monitorear los registros de autenticación en busca de anomalías que se originen desde rangos IP de hoteles. Los equipos de DevSecOps deben asegurarse de que la VPN y la MFA sean obligatorias para el acceso remoto, y considerar la segmentación de red para limitar el radio de explosión si se produce un compromiso del Wi-Fi del hotel.
