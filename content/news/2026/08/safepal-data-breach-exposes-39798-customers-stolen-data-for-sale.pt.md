A SafePal, provedora de carteiras de hardware para criptomoedas, alerta para uma violação de dados que afeta 39.798 clientes após uma falha ser explorada para roubar informações de pedidos; os dados roubados estão agora à venda.

{{< cyber-report severity="High" source="BleepingComputer" target="Clientes da carteira de hardware de criptomoedas SafePal" >}}

A SafePal, provedora de carteiras de hardware para criptomoedas, divulgou uma violação de dados que afeta aproximadamente 39.798 clientes. A violação ocorreu após uma vulnerabilidade ser explorada para roubar informações de pedidos dos clientes, e um ator de ameaças agora afirma estar vendendo os dados roubados.

{{< ad-banner >}}

A natureza exata da falha explorada não foi divulgada, e nenhum identificador CVE foi fornecido. Os dados roubados parecem estar limitados a informações de pedidos, que podem incluir nomes, endereços e detalhes de compra, mas não necessariamente credenciais de carteira ou chaves privadas.

Este incidente destaca o risco contínuo para serviços relacionados a criptomoedas, onde até mesmo dados não financeiros podem ser valiosos para atacantes em campanhas de phishing e engenharia social. Os clientes da SafePal devem ficar atentos a golpes direcionados e monitorar suas contas em busca de atividades suspeitas.

{{< netrunner-insight >}}

Para analistas de SOC, esta violação ressalta a importância de monitorar a exfiltração de dados de sistemas de e-commerce e gerenciamento de pedidos, não apenas da infraestrutura financeira central. As equipes de DevSecOps devem garantir que qualquer aplicação voltada para a web, mesmo aquelas que não lidam diretamente com fundos, seja corrigida prontamente e tenha controles de acesso adequados. Além disso, como dados de pedidos roubados podem alimentar ataques de phishing altamente convincentes, as organizações devem implementar filtragem de e-mail e treinamento de conscientização do usuário focado em ameaças relacionadas a criptomoedas.
