Microsoft связывает глобальные атаки на Wi-Fi в отелях с российской группировкой Midnight Blizzard (APT29), использующей кастомное вредоносное ПО для взлома учетных записей Microsoft 365.

{{< cyber-report severity="High" source="BleepingComputer" target="Wi-Fi сети гостиничного сектора и учетные записи Microsoft 365" >}}

Microsoft выявила глобальную киберкампанию, нацеленную на Wi-Fi сети гостиничного сектора, приписывая ее российскому угрозе Midnight Blizzard, также известному как APT29. Атаки используют кастомное вредоносное ПО для компрометации учетных записей Microsoft 365, что указывает на сложную и устойчивую угрозу.

{{< ad-banner >}}

Кампания подчеркивает риски, связанные с публичными Wi-Fi сетями в отелях, которым часто доверяют деловые путешественники и которые могут служить шлюзом к корпоративным учетным данным. Использование APT29 кастомного вредоносного ПО предполагает индивидуальный подход для обхода обнаружения и сохранения доступа.

Организации, сотрудники которых часто путешествуют, должны знать об этой угрозе и усилить меры безопасности, такие как обязательное использование многофакторной аутентификации и мониторинг необычной активности учетных записей, особенно при доступе из сетей отелей.

{{< netrunner-insight >}}

Для аналитиков SOC эта кампания подчеркивает необходимость мониторинга журналов аутентификации на предмет аномалий, исходящих из IP-диапазонов гостиничного сектора. Команды DevSecOps должны обеспечить обязательное использование VPN и MFA для удаленного доступа и рассмотреть сегментацию сети, чтобы ограничить радиус поражения в случае компрометации Wi-Fi в отеле.
