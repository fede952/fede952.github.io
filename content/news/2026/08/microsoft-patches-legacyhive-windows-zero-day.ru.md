Microsoft устраняет уязвимость Windows нулевого дня, получившую название LegacyHive, о которой стало известно после июльского Patch Tuesday 2026 года. Выпущены обновления.

{{< cyber-report severity="High" source="BleepingComputer" target="Системы Windows" >}}

Microsoft выпустила обновления безопасности для устранения уязвимости Windows нулевого дня, известной как "LegacyHive". Об уязвимости стало известно после июльского Patch Tuesday 2026 года, что указывает на то, что она была публично известна до выхода исправления.

{{< ad-banner >}}

Эти обновления являются частью постоянных усилий Microsoft по защите Windows от активно эксплуатируемых уязвимостей. Хотя конкретные технические детали не приводятся в сводке, статус нулевого дня позволяет предположить, что злоумышленники могли использовать эту уязвимость до выхода патча.

Организациям, использующим Windows, рекомендуется незамедлительно установить последние обновления безопасности, чтобы снизить риск, связанный с этой уязвимостью. Учитывая характер нулевого дня, немедленное обновление критически важно для предотвращения потенциальной эксплуатации.
